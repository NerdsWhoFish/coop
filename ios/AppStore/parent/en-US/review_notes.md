# Cooper The Cop review notes

This app administers a self-hosted Coop server and must be reviewed with Cooper Watch.
The review account and server URL will be supplied in App Store Connect rather than committed to the repository.

1. Connect to the supplied server and sign in with the parent review account.
2. Open Children and select the prepared child profile.
3. Review its allowed channels, blocked channels, keyword rules, devices, and recommendation settings.
4. Open Requests and approve or deny the prepared request.
5. Generate a pairing code, then enter that code in Cooper Watch if a fresh pairing is needed.

The review server uses fictional data and remains available for the review period.
