# Cooper Watch review notes

This app is the viewing side of a self-hosted Coop server and must be reviewed with Cooper The Cop.
The server URL, parent credentials, and pairing instructions will be supplied in App Store Connect rather than committed to the repository.

1. Pair with the prepared child profile using the supplied code.
2. Browse the Home, Shorts, and Subscriptions tabs.
3. Open an approved channel and play a video through the embedded YouTube player.
4. Add a reaction and confirm that watch progress is preserved.
5. Search for the prepared allowed channel, then request the prepared unavailable channel.

The review server uses fictional data and remains available for the review period.
